# Portfolio Documentation

This folder documents the structure and maintenance of the Cian Combalicer portfolio.

## Contents

- [Development](development.md): install, run, validate, and build the site.
- [Architecture](architecture.md): app entry points, routes, shared components, and styling.
- [Projects](projects.md): the portfolio projects and how case studies are built.
- [Admin](admin.md): setting up and using the `/admin` content editor.

The application is a React 19 single-page portfolio built with Vite. Content is editable at `/admin` (backed by Supabase); case studies are served at `/projects/<slug>`.
